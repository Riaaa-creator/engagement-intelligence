## Live Deployment

The Engagement Intelligence dashboard is deployed using Streamlit Community Cloud.

- **Live application:** https://engagement-intelligence-pzretlsxzxg3mtgzhxw9wy.streamlit.app/
- **GitHub repository:** https://github.com/Riaaa-creator/engagement-intelligence
- **Entry-point file:** `app.py`
- **Dependency file:** `requirements.txt`
- **Branch:** `main`

Updates committed to the configured GitHub repository are used to update the deployed application. Dependency changes may trigger a fresh installation and redeployment.
